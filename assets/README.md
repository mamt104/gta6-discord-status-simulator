# Assets

This repository intentionally does not redistribute Rockstar Games artwork.

Optional local files:

- `app-icon.png`: square PNG used as the Windows executable icon during build.
- `rich-presence-cover.png`: the image you upload manually to Discord Rich Presence Art Assets.

Recommended size: 1024 x 1024 pixels. Use artwork you own or are allowed to redistribute.
The asset key expected by default is `gtavi_cover`; you can change it during configuration.
