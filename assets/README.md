# Assets

This directory contains the visual files used by the public project.

Included files:

- `hero-character.png`: the current repository banner with the illustrated character.
- `social-preview.jpg`: the optimized GitHub link-preview image.
- `rich-presence-cover.png`: the square cover to upload manually in Discord Developer Portal under **Rich Presence → Art Assets**.

Use the asset key `gtavi_cover` for `rich-presence-cover.png`; this matches the application's default configuration.

The banner and social preview are original project artwork. The Rich Presence cover is user-supplied unofficial fan artwork. None of these files are official Rockstar Games assets or evidence of access to GTA VI.

Optional local files:

- `app-icon.png`: square PNG used as the Windows executable icon during build.

The included `rich-presence-cover.png` does not need to be replaced unless you want your own artwork. For a replacement, use a square PNG or JPG, preferably 1024 x 1024 pixels, that you are allowed to upload or distribute. You can change the expected asset key during configuration.
